Radio Effect

Broadcast pit-radio character: narrow band, comms compression, a presence lift at 2 kHz, and a mic click at each end.

{{ config.radio_effect.intensity }}

How narrow the radio band is and how hard it saturates. Higher is more like a real pit radio; at maximum it starts to distort.

1.0 gives a 400–3000 Hz comms band, closest to an F1 world feed.

{{ config.radio_effect.compression }}

Evens out loud and quiet words. This is most of the effect.

{{ config.radio_effect.noise }}

Band-limited, not hiss. Real race radio is nearly clean — keep this low, or at 0 for digital-clear.

{{ config.radio_effect.low_cut }} Hz

Everything below this is thrown away. Raising it thins the voice out, which is most of what makes it sound like radio.

{{ config.radio_effect.high_cut }} Hz

Everything above this is thrown away. Lowering it dulls the voice and hides sibilance.

Restore Defaults

Puts every setting back to how it ships. Your API keys, chosen voice, favourites, pronunciations and push-to-talk binding are kept. Voice and Audio can be reset on their own.

Performance

Runs AIRE below normal priority, so if the sim and the engineer want the same core, the sim wins. Costs nothing when the machine is not busy — priority only decides who is scheduled under contention. Takes effect on restart.

Idle, AIRE uses about 0.3% of a modern CPU. Most of its memory is the settings panel, not the engineer.
